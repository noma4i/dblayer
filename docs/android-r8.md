# Android R8 checks

The package ships `kotlin/consumer-rules.pro`. An app with R8 minification gets these rules from the AAR.
They keep JNA's core and pointer classes, the public fields and constructors of JNA structures, the public methods of callbacks and the names of native methods. `RuntimeVisibleAnnotations` keeps `Structure.FieldOrder`.

```proguard
-dontwarn java.awt.**
-keep class com.sun.jna.* { *; }
-keep class com.sun.jna.ptr.* { *; }
-keepattributes RuntimeVisibleAnnotations
-keep class com.noma4i.dblayer.** extends com.sun.jna.Structure {
    public <fields>;
    public <init>(...);
}
-keep class com.noma4i.dblayer.** implements com.sun.jna.Callback {
    public <methods>;
}
-keepclassmembers class com.noma4i.dblayer.** {
    native <methods>;
}
```

The generated `UniffiLib` and `IntegrityCheckingUniffiLib` objects register natives with `Native.register`, which takes `Class` objects. Their classes can be renamed and their native method names stay.
Records, enums and errors use generated byte-buffer converters, with no field-name lookup and no reflective construction. Their names can change.
The JNA rule follows its Android documentation: <https://github.com/java-native-access/jna/blob/master/www/FrequentlyAskedQuestions.md#jna-on-android>.

## What the check does

`kotlin/r8-check` compiles the generated `dblayer.kt` and a small caller.
Its Android application enables release minification and consumes `kotlin/consumer-rules.pro`.
The JVM probe runs R8-optimized class files against the host native library. It checks native calls, structures, callbacks, a record, an enum and an error.
Both mappings must rename `Config`, which rejects a package-wide keep rule.
The check does not run on a device.

## Reproduce

Run `bash scripts/build_kotlin.sh --host`, then `gradle -p kotlin/r8-check probe` through the build slot.
Set `ANDROID_HOME` to the Android SDK directory.
Use `-Prules=/absolute/path/to/rules.pro` to check a modified rule file.
The full check includes the `gradle-r8` step after it generates the Kotlin bindings.

## Release profile

The workspace release profile sets `opt-level = 3`, `lto = false`, `codegen-units = 1`, `strip = "symbols"` and `panic = "unwind"`. It applies to the Android and iOS builds. Panic unwinding stays on for UniFFI.
